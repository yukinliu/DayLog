# DayLog · 时光日志

个人时间记录与状态复盘工具。

## 版本说明

- `daylog-standalone/`：纯前端独立版，无注册、无云同步；作为独立版本保留。
- `daylog-cloud/`：云端版，基于腾讯云 CloudBase，支持登录、Pro 权益与云同步；这是后续持续开发的核心目录。

## 功能清单

- 项目与 DDL 管理
- 事件记录与复盘统计
- 日期筛选与日历视图
- 想法与状态记录
- 数据云同步
- Markdown 导出

## 开发说明

当前主要开发目录：

`daylog-cloud/`

`daylog-standalone/` 不是账号体系里的“基础版”，而是无后端的纯前端独立版本。
