# 见己版本记录

本文件记录“刘迷糊 DayLog · 见己”面向用户发布的版本变化。

版本号采用 `主版本.次版本.修订号`：

- 主版本：产品或数据结构发生重大变化；
- 次版本：增加较完整的新功能；
- 修订号：修复问题、优化体验或调整内容。

新版本发布时，在当前版本上方追加记录，并同步更新：

- `package.json` 中的 `version`；
- `src-tauri/tauri.conf.json` 中的 `version`；
- `public/data/daylog-content.json` 中的 `release`；
- 飞书版本下载页中的版本号、安装包和更新说明。

---

## v0.1.1 · 内测版

发布日期：2026 年 8 月 13 日

### 新增

- 记录页增加“今日已记录”轻量回显，减少重复检查记录的记忆负担；
- 明细页增加全部本地记录搜索，并默认展开当天第一条事实经历；
- 项目页增加“全部 / 临期 / 新增 / 逾期”关注视图，切换后默认展开第一项；
- 项目截止日期支持“长期有效 / 暂未确定 / 指定日期”相互切换。

### 优化

- 每次真正打开或重新唤醒应用时显示玻璃浮层问候与最近记录摘要；开始操作后，问候语落回记录页顶部；
- 同一次打开期间保持同一句问候语，应用内切换页面不再重复更新；
- 调整明细页自我觉察与事实经历的空间权重；
- 优化日历有记录日期的主题底色，增强辨识度并降低视觉压迫感；
- 项目状态与截止日期逻辑解耦，长期项目不再被默认日期干扰。

### 修复

- 修复项目从长期有效或暂未确定切换到指定日期时无法保存的问题；
- 修复切换项目筛选或日期后详情仍停留在旧条目的问题；
- 修复页面内部切换会重新抽取问候语的问题。

### 安装包

- macOS：`见己_0.1.1_aarch64.dmg`，适用于 Apple 芯片 Mac；
- Windows：`见己_0.1.1_x64-setup.exe`，适用于 64 位 Windows 10、Windows 11。

## v0.1.0 · 内测版

发布日期：2026 年 8 月 12 日

### 新增

- 支持分别记录自我觉察与事实经历；
- 支持一天保存多条想法和多段事实经历；
- 支持按日期回看、修改和删除记录；
- 支持项目创建、状态调整、合并、删除及关联经历查看；
- 支持本周、本月、自定义区间和全部记录统计；
- 支持查看感受变化、想法汇总、时间分布和完成状态；
- 支持月历查看每天投入时间最多的三个项目及“更多”；
- 新增“关照”页面，可随机获得一件具体的小事；
- 支持七组敦煌壁画色系主题；
- 支持 Apple 芯片 Mac 和 64 位 Windows 10、Windows 11；
- 支持本地资料库与每日 Markdown 文件；
- 支持从旧数据制作并打开独立迁移资料库；
- 新增产品说明、版本更新、安装说明和反馈入口；
- 新增不包含记录内容的匿名内测统计。
- 记录页新增当天已保存内容的轻量回显；
- 明细页新增全部本地记录搜索与快速定位；
- 每次启动或重新打开主窗口时，以玻璃浮层显示不同问候语与最近记录摘要；用户开始操作后问候语落回原位置。

### 优化

- 统一产品名称为“刘迷糊 DayLog · 见己”，并更换应用图标；
- 调整记录、明细、项目、统计、日历、关照和设置页面的视觉层级；
- 优化项目色彩，降低颜色过近或过于浓烈的问题；
- 优化推荐语及复制交互，复制内容自动附带产品说明与下载链接；
- 优化 macOS 窗口拖动与关闭行为；
- macOS 关闭窗口后保留应用运行，点击 Dock 图标可重新打开；
- Windows 关闭主窗口后退出应用；
- 远程运营内容改为每次启动检查，网络失败时使用最近缓存或安装包内置内容。
- 自我觉察与事实经历调整为约 38% / 62% 的上下空间；
- 明细页、项目页及筛选切换后默认展开第一条内容；
- 项目状态与截止日期解耦，新增“全部 / 临期 / 新增 / 逾期”关注视图；
- 降低日历有记录日期的主题底色强度，保留项目条原有颜色。

### 修复

- 修复部分情况下窗口无法拖动的问题；
- 修复旧远程内容缓存覆盖新推荐语的问题；
- 修复部分保存按钮失效、空状态位置不协调及日期状态颜色不随主题变化的问题；
- 修复项目切换、分类切换和状态调整后难以继续定位的问题；
- 修复日历中项目条目显示不完整的问题；
- 修复设置与关照浮层点击外部无法关闭的问题。

### 数据与隐私

- 记录、项目和设置保存在用户选择的本地资料库中；
- 应用不上传记录文字、感受内容、事件内容、项目名称、资料库路径或资料库文件；
- 匿名统计仅用于了解内测激活与基础功能使用情况，统计服务不可用不影响离线记录。

### 安装包

- macOS：`见己_0.1.0_aarch64.dmg`，适用于 Apple 芯片 Mac；
- Windows：`见己_0.1.0_x64-setup.exe`，适用于 64 位 Windows 10、Windows 11；
- Intel 芯片 Mac 暂不支持；
- 当前内测安装包尚未完成 Apple Developer ID 公证或 Windows 代码签名。
