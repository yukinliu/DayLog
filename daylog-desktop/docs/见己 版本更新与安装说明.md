# 见己｜版本更新与安装说明

## 当前版本

**v0.1.1 · 内测版**
发布日期：2026 年 8 月 13 日

支持：

- Apple 芯片 Mac（M1、M2、M3、M4 及后续同架构机型）；
- 64 位 Windows 10、Windows 11。

Intel 芯片 Mac 暂不支持。

## v0.1.1 更新内容

- 新增“今日已记录”轻量回显，方便确认当天已保存的想法与事实经历；
- 新增明细页全局搜索，并默认展开当天第一条事实经历；
- 项目页新增“全部 / 临期 / 新增 / 逾期”视图，切换后自动展开第一项；
- 项目截止日期支持“长期有效 / 暂未确定 / 指定日期”相互切换；
- 每次真正打开或重新唤醒应用时显示问候语与最近记录摘要；
- 同一次打开期间保持同一句问候语，应用内切换页面不再重复更新；
- 优化明细页区域权重、日历日期辨识度及项目日期逻辑。

## 主要功能

- 记录感受、想法与事实经历；
- 按日期回看、修改和删除记录；
- 管理项目并查看关联经历；
- 查看感受趋势、时间分布与完成状态；
- 从日历浏览每天的时间重心；
- 随机获得一件关照小事；
- 将数据保存在用户选择的本地资料库中；
- 自动生成按日期整理、可以直接阅读的 Markdown 文件；
- 使用不包含记录内容的匿名统计了解内测运行情况。

- 修复部分远程文案被旧缓存覆盖的问题；

## 在 macOS 上安装

1. 下载 `见己_0.1.1_aarch64.dmg`。
2. 双击打开 DMG。
3. 将“见己”拖入 `Applications（应用程序）` 文件夹。
4. 从“应用程序”中打开见己。
5. 创建新的本地资料库，或选择已有资料库。

当前内测版尚未完成 Apple Developer ID 签名与公证，因此 macOS 可能阻止第一次打开。

可以依次尝试：

1. 在 Finder 的“应用程序”中找到“见己”；
2. 按住 Control 键点击应用，选择“打开”；
3. 在出现的提示中再次选择“打开”。

如果仍然被阻止：

1. 先尝试打开一次见己；
2. 进入“系统设置 → 隐私与安全性”；
3. 在相关安全提示中选择“仍要打开”；
4. 按照系统提示确认。

如果系统提示“应用已损坏，无法打开”，且没有“仍要打开”的选项，请先确认安装包来自上方固定页面，再打开“终端”，粘贴并运行：

```bash
xattr -dr com.apple.quarantine "/Applications/见己.app"
```

完成后重新打开见己。该命令只移除见己应用的下载隔离标记，不会修改资料库。

### macOS 关闭窗口后

点击左上角红色关闭按钮会关闭窗口，但见己仍在运行。这与许多 macOS 应用的行为一致：

- 点击 Dock 中的见己图标可以重新打开窗口；
- 如果希望完全退出，请在菜单栏选择“见己 → 退出见己”，或按 `Command + Q`。

## 在 Windows 上安装

1. 下载 `见己_0.1.1_x64-setup.exe`。
2. 双击安装程序，按照提示完成安装。
3. 从开始菜单或桌面快捷方式打开见己。
4. 创建新的本地资料库，或选择已有资料库。

当前内测版尚未进行 Windows 代码签名，因此 Microsoft Defender SmartScreen 可能提示“Windows 已保护你的电脑”。确认安装包来自上方固定页面后：

1. 点击“更多信息”；
2. 核对应用名称为“见己”；
3. 点击“仍要运行”。

Windows 点击关闭按钮后会退出应用。退出前，如有未保存草稿或保存失败的内容，见己会进行提示。

## 如何获取更新

见己会在启动时读取公开的版本信息，但不会自动下载或替换应用。

- 没有新版本时，“设置 → 关于”会显示“已是最新版”；
- 发现新版本后，设置入口会出现提示点，“关于”中会显示下载入口。

更新时：

1. 完全退出正在运行的见己；
2. 从固定下载页面获取对应系统的最新安装包；
3. macOS 将新的见己拖入“应用程序”，并选择替换；Windows 运行新的安装程序；
4. 重新打开见己。

应用通常会继续使用原来的资料库。如果再次出现资料库选择，请选择原来的资料库文件夹。

更新应用不会主动删除记录。为了稳妥，更新前仍建议备份整个资料库文件夹。

## 应用与资料库的区别

- **见己.app、DMG 或 Windows 安装程序**：应用本身，可以更新或重新安装；
- **见己资料库**：你的记录、项目和设置，需要自行妥善保管。

更新时只替换或重新安装应用，不要删除或覆盖自己的资料库。

## 卸载

### macOS

完全退出见己后，将“应用程序”中的见己移到废纸篓。

### Windows

进入“设置 → 应用 → 已安装的应用”，找到见己并选择卸载。

卸载应用不会主动删除你选择的资料库。如果确认不再需要记录，请先完成备份，再自行处理资料库文件夹。
