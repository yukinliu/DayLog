# DayLog Desktop 视觉系统文档

> 最后更新：2026-08-12
> 版本：v0.2.0
> 适用范围：`daylog-desktop` macOS 本地桌面版
> 状态：桌面视觉与交互基线

## 一、视觉命题

DayLog Desktop 的视觉方向是：

```text
雾青纸本 · 本地时光工作台
```

“纸本”代表温度、可阅读和时间留下的痕迹；“工作台”代表桌面端的稳定结构、信息密度和可靠反馈。

它不应像：

- 卡片不断向下堆叠的网页首页。
- 冷硬的商业数据后台。
- 以可爱装饰代替信息层级的手账应用。
- 用图表制造价值感的效率仪表盘。

核心气质：

- 轻、静、克制。
- 温和但不模糊。
- 稳定但不笨重。
- 有纸面感，但操作反馈符合桌面软件预期。

页面性格：

```text
记录页轻：减少阻力
明细页实：便于校正
统计页清：帮助理解
项目页稳：保持连续
日历页静：呈现时间
```

## 二、视觉优先级

视觉必须先表达状态，再表达装饰。

优先级从高到低：

1. 当前资料库和保存状态。
2. 当前页面、日期或统计范围。
3. 主要内容与主要动作。
4. 选择、筛选和编辑状态。
5. 品牌氛围与装饰。

任何“看起来已经保存”的界面都必须以真实磁盘结果为依据。保存失败不能只出现在控制台。

## 三、应用骨架

### 3.1 总体布局

```text
┌────────┬────────────────────────────────────┐
│ 侧边栏 │ 顶部栏：页面 / 范围 / 保存状态     │
│        ├────────────────────────────────────┤
│        │ 中央内容                 详情面板   │
└────────┴────────────────────────────────────┘
```

- 侧边栏保持固定宽度。
- 顶部栏只显示当前页面需要的信息。
- 中央内容承担浏览和输入。
- 详情面板用于选中对象的查看和普通编辑。
- 高风险操作使用弹窗，不把所有编辑都弹窗化。

### 3.2 侧边栏

功能区顺序：

```text
记录
明细
统计
项目
日历
```

产品区位于底部：

```text
充能
设置
```

当前页状态使用：

- 左侧 2–3px 色条。
- 淡雾青背景。
- 图标和文字同时增强。

不使用大面积实色高亮。

### 3.3 顶部栏

产品名直接居中放入 macOS 原生标题栏所在的约 38px 空间，显示 `刘迷糊 DayLog · 见己`；不再额外占用页面内的一行品牌栏。侧边栏已经承担当前位置表达，因此不重复显示功能页名称；保存成功只在标题栏右侧短暂显示。

示例：

```text
                    刘迷糊 DayLog · 见己
```

品牌名是产品内容配置，不从登录用户或资料库名称动态生成。

### 3.4 macOS 窗口

原生标题栏与自定义标题栏二选一：

- 使用原生标题栏时，不在页面里绘制假的红黄绿按钮。
- 使用自定义标题栏时，必须接通真实窗口拖动和窗口控制，并处理安全区域。

首个 MVP 优先使用原生窗口行为，减少不必要的桌面仿真。

## 四、色彩系统

### 4.1 基础色

```text
App Background      当前主题的纸色
Surface             #FFFDF8
Surface Soft        当前主题的柔和底色
Border              主题强调色的低透明度版本
Text Primary        #2F2D29
Text Secondary      #6F6B64
Muted               #9D9991
```

### 4.2 品牌与状态色

品牌强调色取自当前敦煌主题；项目识别色使用独立 12 色板。状态色保持低饱和，并同时配合图标或文案。

使用规则：

- 当前主题强调色：选择、连续性、保存、新增等主要动作。
- 烟蓝：中性辅助状态。
- 暖金：圆满完成。
- 砖红：删除、保存失败和不可恢复风险。
- 灰色：暂停、不可用、次要信息。

不要使用高饱和红绿蓝，也不要用颜色作为唯一状态信号。

### 4.3 主题

MVP 提供七套来自敦煌壁画色系的低饱和纸张感外观：

```text
石青  #4F727A / 柔和底 #DDE8E6 / 纸色 #F4F1E8
石绿  #5F7865 / 柔和底 #E2E8DC / 纸色 #F5F1E7
赭石  #94604C / 柔和底 #E9DCD1 / 纸色 #F6EFE5
朱砂  #9A574E / 柔和底 #ECDAD5 / 纸色 #F5EEE7
绀青  #5D687F / 柔和底 #DFE2E8 / 纸色 #F3F0E8
紫棠  #79677B / 柔和底 #E6DEE5 / 纸色 #F5F0EB
黄丹  #A8783C / 柔和底 #ECE1CD / 纸色 #F6F0E4
```

主题只改变背景、强调色和图表色阶，不改变组件尺寸、信息层级和状态语义；设置页只显示一排紧凑色点。

项目使用独立的 12 色稳定色板：石青 `#527984`、朱砂 `#9B6254`、石绿 `#667D61`、黄丹 `#AA844B`、绀青 `#5D6882`、赭石 `#88664F`、青黛 `#4D7C70`、紫棠 `#7C6A80`、秋香 `#858155`、胭脂 `#986875`、烟蓝 `#72889A`、茶褐 `#75645B`。项目色只承担识别，不随主题切换；整体保持敦煌色系的低饱和质感，同时避免相邻色过近或单色过于浓烈。

## 五、字体与排版

```css
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue", sans-serif;
```

字号建议：

```text
范围与日期标题：16px
关键指标：17px
区块摘要：14px
正文与列表：12–13px
辅助信息：10–11px
```

规则：

- 不使用网页式超大 Hero 标题。
- 正文和表单保证中文阅读稳定。
- 数字使用等宽数字特性时，不更换整体字体。
- 长文本在列表中省略，在详情面板展示完整内容。
- 标题上方留白大于下方留白。

## 六、间距、边框与层级

建议使用 4px 基础网格：

```text
4 / 8 / 12 / 16 / 24 / 32
```

- 页面边距：24px 左右。
- 面板内边距：16–20px。
- 表单字段间距：12–16px。
- 普通圆角：8–10px。
- 弹窗圆角：12px。
- 边框默认 1px，使用低对比颜色。
- 阴影只用于浮层和弹窗，不给每张内容块加阴影。

同一页面最多出现三层可见容器，避免“卡片里面再套卡片”。

## 七、核心状态组件

### 7.1 保存状态

```text
未修改：不显示或使用中性文本
保存中：小型进度指示 + 保存中
已保存：短暂显示对勾 + 已保存到本地，约 1.6 秒后隐藏
保存失败：砖红状态条 + 重试
```

保存失败状态必须保持，直到重试成功或用户主动处理。不要用一闪而过的 Toast 承载唯一错误信息。

### 7.2 空状态

空状态说明“这里为什么为空”和“下一步能做什么”。

示例：

```text
今天还没有事实经历
去记录页留下一条经历
```

不要使用大插画占据主要空间。

### 7.3 加载与错误

- 打开资料库时显示明确的加载页，不先渲染测试数据。
- JSON 损坏时显示文件、原因和恢复操作。
- 权限不足时提供重新选择和 Finder 入口。
- 页面级失败使用稳定错误面板，不让主界面无提示白屏。

## 八、按钮与表单

### 8.1 按钮

主按钮：保存、新增、确认，使用暖棕或土橙。

次按钮：筛选、查看、切换，使用浅底或细边框。

危险按钮：删除和覆盖，使用低饱和砖红；确认弹窗中与取消按钮拉开距离。

每个局部区域只有一个视觉主按钮。

### 8.2 表单

- 标签位于控件上方。
- 必填状态、错误和帮助文本靠近字段。
- 输入错误时不清空内容。
- 日期、分钟等结构化字段使用原生或明确格式控件。
- 自动保存字段必须显示保存状态；否则使用明确保存按钮。
- 项目名称和想法不能每输入一个字符就表现为一次完整保存。

### 8.3 弹窗

弹窗只用于：

- 删除确认。
- 项目合并。
- 更换资料库。
- 数据恢复。
- 其他不可逆或跨资料库操作。

规则：

- 默认尺寸可直接完成任务。
- 内容可滚动，底部操作固定。
- Escape 取消，Return 只在安全时确认。
- 明确说明影响的数据数量和后果。

## 九、记录页

记录页是最轻的页面。

结构：

```text
问候语横幅
今日录入摘要
感受与想法（主要）       事实经历（辅助）
```

- 问候语使用轻量横幅，不做 Hero 卡片。
- 两类记录职责不同；宽窗口左右并列，感受与想法约占 56%，事实经历约占 44%；窄窗口上下排列。
- 感受与想法偏雾青并保留更大的持续书写空间，突出“念起觉心，知深见己”的自我觉察主张。
- 事实经历偏纸白与暖棕，事件备注明确为“事实补充”，避免与想法记录混淆。
- 保存按钮靠近对应表单底部。
- 成功后只清理已确认保存的字段。

情绪选择同时显示 emoji、文案和选中轮廓，不能只靠颜色。

## 十、明细页

明细页强调扫描和校正。

结构：

```text
日期切换与当日摘要
一天的内在记录：感受 / 想法与觉察
一天的外在经历：完成状态 / 项目时间去向 / 所选事件详情
```

- 左侧日期栏固定为窄栏，从最早记录到当前连续列出月份并独立滚动；日期单元使用固定正方形与严格居中。
- 页面内减少彼此割裂的同权重卡片，用内在与外在两块连续区域建立阅读顺序。
- 内在与外在区域统一使用 `40% / 60%` 分栏，两条纵向分界线必须严格对齐。
- 内在记录高度约 198px；想法正文使用 13px，在固定区域内纵向滚动。
- 想法原位编辑使用有限高度文本框和明确的“取消 / 保存”，不使用失焦自动保存。
- 时间去向按项目汇总；圆环显示比例，图例只显示项目名称和投入时间。
- 左下默认列出当日全部事件且不选中任何一条；点击项目筛选事件，再次点击恢复全部事件。
- 事件详情直接编辑，停止输入后防抖保存；保存状态必须可感知。
- 选中项使用淡青底与左侧色条。
- 删除按钮平时弱化，进入详情后才显示完整操作。
- 想法编辑不挤占事件详情；短编辑可原位，长编辑进入独立编辑状态。
- 日期改变后焦点和选中项要有可预测行为。

## 十一、统计页

统计页负责区间复盘，不做成商业仪表盘。

结构：

```text
区间选择
一行概览
情绪趋势 / 想法数量
时间分布 / 完成状态
阶段复盘
```

概览优先使用一行摘要或紧凑数字组，不使用六张同权重大卡片。

### 11.1 情绪趋势

- 主线使用青绿。
- 情绪点同时使用 emoji 或形状。
- 中性线明确但不过重。
- 日期多时横向滚动，不强行压缩。

### 11.2 时间分布

- 中心显示总时间。
- 图例显示项目名称、时间和比例。
- 同一项目在项目页、日历和统计中保持稳定颜色。
- 项目按投入降序累计，累计占比首次达到或超过 80% 时停止纳入圆环；余下项目合并为中性色“其他”。
- 圆环扇区与图例同时显示百分比；只有一个项目时仍保持一致的圆环语义。

### 11.3 完成状态

```text
圆满完成：暖金
有所推进：青绿
保底完成：雾蓝
计划外：暖棕
```

必须同时显示中文文案、数量和比例。

## 十二、项目页

结构：

```text
主筛选 + 新增项目
项目列表                 项目详情
```

### 12.1 项目列表

每行显示：

```text
项目色点  项目名称           累计投入
          DDL / 状态 / 天数
```

- 未命名项目始终置顶。
- 已过期项目使用低饱和警示，不使用危险红。
- 完成项目降低对比度。
- 暂停项目使用雾灰状态。
- 列表不使用横向卡片滑动。

### 12.2 项目详情

```text
项目名称                  更多
累计投入 / 记录天数
DDL 类型 / 日期
自然状态 / 完成 / 暂停
最近事实经历
```

合并和删除收进“更多”。编辑时不要每个字符都闪烁“已保存”。

项目列表和详情组成固定高度的左右工作区，各自处理长内容滚动。项目颜色仅作为小圆点或细色条使用，不大面积铺色。

修改项目状态后保持当前详情，避免正在操作的项目突然消失。切换项目主分类时清空选择，不自动选中该分类中的第一个项目。

项目详情的四种状态使用统一分段控件：图标、字号和宽度一致，仅当前状态使用主题色与纸面高亮，不让四种语义色彼此竞争。

### 12.3 明细、统计与日历密度

- 明细页左侧保留从最早记录到当前的连续月份，窄栏独立纵向滚动；右侧以“内在记录 / 外在经历”两区完成当日回看。
- 统计页在一页内展示区间、四项指标、感受趋势、按日期倒序的想法条数、时间分布和完成状态；时间分布位于左侧较宽区域，长列表在卡片内部滚动。
- 完成状态固定展示四项，包括数量为 0 的状态；四项作为一个整体在所属卡片中垂直居中。
- 日历每天最多展示投入时间前三的已命名项目；同一项目稳定同色，其余项目和未分类投入合并为中性色“更多”。日期格在五周和六周月份中都必须容纳完整的“三项目 + 更多”四行结构。

### 12.4 新增项目

1. 点击“新增项目”。
2. 如已有未命名项目，先确认是否继续。
3. 新项目置顶并自动打开详情。
4. 焦点进入项目名称。
5. 用户完成名称和 DDL 后形成一次有效保存。

## 十三、日历页

日历页只浏览，不编辑。

- 月历格保持纸面感，边框轻。
- 事实经历用项目色条展示。
- 只有感受记录时使用小型雾青点，不显示虚假的 0 分钟项目条。
- 每格固定预留四行摘要：最多三个主要项目，其余汇总为“更多”；不得因月份跨六周而裁切末行。
- 点击有任意记录的日期进入明细页。
- 没有记录的日期保持安静，不重复显示“没有记录”。

## 十四、设置与资料库

资料库卡片必须清楚显示：

- 资料库名称。
- 可截断但可复制的路径。
- 当前状态：正常、只读、错误或正在切换。
- 更换资料库。
- 在 Finder 中显示。

路径不是页面视觉主角，但不能藏在 Tooltip 中。

更换资料库弹窗说明：

```text
当前资料库
未完成保存状态
打开已有资料库 / 新建资料库
取消
```

关于区域保留当前产品版本、更新状态和产品说明入口，不重复展示产品名或隐私说明。版本检查保持后台、被动；只有发现新版本时才出现飞书下载链接，不设置独立“检查更新”按钮。

## 十五、响应与窗口尺寸

目标窗口：

```text
默认 1280 × 820
建议最小 960 × 680
```

在较窄窗口中：

- 侧边栏可缩为图标模式，但保留可访问名称。
- 双栏表单改为纵向排列。
- 列表与详情优先保持列表可用，详情可成为覆盖面板。
- 统计图允许横向滚动，不压缩到无法阅读。
- 设置和充能不得遮挡整个主窗口且无关闭入口。

### 15.1 充能抽屉

充能使用不超过约 `420px` 的右侧抽屉，内部按“充能行动—其他产品—分享 DayLog”纵向排列，三组内容始终完整铺开。充能卡是第一视觉焦点，使用主题色的低饱和背景和宋体标题，不使用高速旋转、彩色扇区或庆祝动效。其他产品使用紧凑横向卡片，标题说明价值；推荐文案位于最下方并完整显示，通过字号、留白和底色建立次级层级，不使用折叠交互。

## 十六、动效与反馈

- 页面切换不使用大幅滑动。
- 浮层出现使用 120–180ms 淡入与轻微位移。
- 保存成功不做庆祝动画，只给克制确认。
- 删除和合并后保持列表位置稳定，并清楚更新选择状态。
- 尊重 macOS“减少动态效果”设置。

## 十七、无障碍与键盘

- 所有图标按钮有可访问名称。
- 当前页面、选中状态和错误不只靠颜色。
- 键盘焦点轮廓清楚可见。
- Tab 顺序符合视觉顺序。
- 弹窗打开后锁定焦点，关闭后回到触发按钮。
- 图表提供文字摘要和图例。
- 文本与背景满足正常正文对比度要求。

## 十八、当前视觉收口任务
