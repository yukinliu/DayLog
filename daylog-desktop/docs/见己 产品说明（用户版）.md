# 刘迷糊 DayLog · 见己

> 安静记录生活，也更清楚地看见自己。

## 见己是什么

见己是一款将数据保存在电脑本地的个人时光日志。

它不催你打卡，也不评价效率。你可以在这里留下两种同样重要的记录：

- **自我觉察**：此刻有什么感受，脑海里出现了什么想法。
- **事实经历**：这段时间真实发生了什么，为它投入了多久。

很多时候，我们只记得自己“做过什么”，却忘了当时如何感受；也可能经历了许多情绪，却很难看清它们发生在怎样的生活里。见己把内在感受与外在经历放在同一天里，帮助你慢慢看见自己的时间、注意力与生命经验。

你不需要每天写很多，也不必急着把想法整理成结论。从一种说不清的感受、一句刚刚闪过的话，或一件真实发生的小事开始，就已经足够。

## 你可以怎样使用

### 记录自我觉察

选择当天的感受，写下此刻的想法。一天可以保存多条想法，也可以补记过去的日期。

保存后，想法输入区域会清空，日期和感受仍会保留，方便继续记录。这不代表一天只能写一条，而是希望每一个当下都能被单独留下。

### 留下事实经历

记录事情发生的日期、时间段、投入时间、所属项目、完成状态和必要的补充信息。

事实经历用于还原生活，不是要求你把每一分钟都填满。没有归属项目的事情也可以直接保存。

### 回看某一天

在明细页把一天的自我觉察和事实经历放在一起查看。你可以直接修改想法，调整或删除事件，并通过时间分布看见当天的时间去了哪里。

### 观察持续发生的事

项目可以处于进行中、待计划、暂停中或已完成。你可以查看一个项目已经投入多少时间，以及与它相关的事实经历。

项目不是复杂的任务系统，而是一种观察长期投入的方式。

### 看见一段时间的变化

统计页支持本周、本月、自定义区间和全部记录。你可以查看：

- 记录天数、想法数量和事实经历数量；
- 感受体验的变化；
- 时间在不同项目之间的分布；
- 不同完成状态所占的比例。

这些结果用于帮助你发现倾向，不用于给生活评分。

### 从日历看时间重心

日历会优先展示每天投入时间最多的三个项目，其余内容汇总为“更多”，帮助你快速看见一个月的主要时间去向。

### 给此刻一点关照

不知道怎样休息或转换状态时，可以随机获得一件轻松、具体的小事。它不是新的待办任务，只是一个照顾此刻的微小邀请。

## 数据保存在你的电脑里

见己不需要注册账号。第一次使用时，你需要创建或选择一个本地资料库。记录、项目和设置都保存在这个文件夹中，并生成可以直接阅读的每日 Markdown 文件。

请记住：

- **资料库文件夹就是你的数据本体。**
- 更换或卸载见己，不会主动删除资料库。
- 不要随意删除资料库中的文件。
- 建议定期备份整个资料库文件夹。
- 更换电脑时，将整个资料库复制到新电脑，再在见己中选择该文件夹即可继续使用。

见己不会上传你的记录内容、项目名称、资料库路径或资料库文件。

## 关于匿名使用统计

为了确认内测版本是否能够正常运行，并了解哪些基础功能被实际使用，见己会发送少量匿名统计信息：

- 首次激活；
- 每日首次打开；
- 首次保存自我觉察；
- 首次保存事实经历；
- 打开版本更新链接；
- 打开反馈链接；
- 应用版本、操作系统和事件发生日期。

统计使用随机生成并经过哈希处理的安装标识，不包含姓名、邮箱、记录文字、感受内容、事件内容、项目名称、资料库路径或其他文件内容。

统计服务不可用时，不会影响记录、保存和离线使用。

## 反馈与建议

如果你遇到显示异常、无法保存、操作无响应，或有任何使用感受，可以前往：

[提交反馈与建议](https://my.feishu.cn/docx/N2OTdIIYoo6aTZx98TAcJavmnte)

为了更快定位问题，建议附上使用的系统、发生问题的页面、操作过程和截图。请不要在反馈中提交私密的记录内容或完整资料库。

## 从今天开始

你可以先写下：

- 我此刻是什么感受？
- 刚才有什么想法一闪而过？
- 今天真实发生了什么？
- 我的时间去了哪里？

不必急着解释，也不必马上改变什么。

记录本身，就是一次看见。
